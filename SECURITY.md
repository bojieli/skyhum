# Security and safety reports

Please report privately, not in a public issue:

- a vulnerability in skyhum (for example, a crafted audio or GeoJSON file that runs code or reads files it should
  not);
- a way the `find` gate can be bypassed by accident, or output that leaks a point estimate below the strict
  threshold;
- a use of the tool that harms people and that the docs do not address;
- a platform-specific finding you would like handled before it is public.

How: use GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability").

We aim to acknowledge reports within a week. Please give us reasonable time to respond before disclosing.

Supported versions: the latest release only. skyhum is alpha software.
